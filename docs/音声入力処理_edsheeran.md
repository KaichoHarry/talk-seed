# 音声認識モジュール設計書

## 1. 担当範囲

本モジュールは、会話参加者の発話音声を取得し、テキストデータへ変換する機能を担当する。

具体的には、以下の機能を提供する。

* マイクからの音声取得
* 音声データの前処理
* 音声認識処理
* テキストデータ生成
* 後続モジュールへのテキスト送信

本モジュールによって生成されたテキストは、会話支援AIモジュールへ送信され、会話内容の理解や応答生成に利用される。

---

## 2. システム構成

本モジュールは、システム全体における入力処理部分として機能する。

会話参加者の発話を取得し、音声認識によってテキストへ変換した後、会話支援AIモジュールへ送信する。

```text
┌─────────────┐
│  会話参加者  │
└──────┬──────┘
       │ 音声
       ▼
┌─────────────┐
│   マイク入力  │
└──────┬──────┘
       ▼
┌─────────────┐
│   音声取得   │
└──────┬──────┘
       ▼
┌─────────────┐
│   音声認識   │
└──────┬──────┘
       ▼
┌─────────────┐
│ テキスト生成 │
└──────┬──────┘
       ▼
┌─────────────┐
│ AIモジュール │
└─────────────┘
```

## 3. 機能要件

### 3-1. 音声取得機能

#### 概要

会話参加者の発話音声をマイクから取得する。

#### 入力

* 会話参加者の音声

#### 出力

* 音声データ

#### 処理内容

1. マイクデバイスを起動する
2. 音声データを取得する
3. 音声認識処理へ渡す

---

### 3-2. 音声認識機能

#### 概要

取得した音声データをテキストへ変換する。

本システムでは音声認識エンジンとして Whisper の利用を想定している。

#### 入力

* 音声データ

---

### 3-3. リアルタイム認識機能

#### 概要

会話中の音声を継続的に認識し、リアルタイムでテキストへ変換する。

#### 入力

* 音声ストリーム

#### 出力

* テキストデータ

#### 要件

* 会話の流れを妨げない速度で認識結果を出力する
* 発話終了後、速やかに認識結果を確定する

---

### 3-4. テキスト送信機能

#### 概要

認識結果を後続のAIモジュールへ送信する。

#### 出力形式

```json
{
  "timestamp": "2026-06-16T12:30:00",
  "text": "最近どこか旅行行った？"
}
```

#### 項目説明

| 項目名       | 説明        |
| --------- | --------- |
| timestamp | 発話を認識した時刻 |
| text      | 認識された発話内容 |

---

## 4. 非機能要件

### 4-1. 応答速度

発話終了から認識結果出力までの時間を2秒以内とする。

### 4-2. 認識精度

静かな環境において **90%以上の認識精度** を目標とする。

### 4-3. 可用性

30分以上の連続利用において安定して動作すること。

### 4-4. 対応言語

初期バージョンでは日本語のみを対象とする。
