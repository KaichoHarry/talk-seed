# TalkSeed
## 概要

TalkSeedは、会話が途切れた時や何を話せばよいかわからない時に、話題や質問、ツッコミなどを提案する会話支援AIです。

雑談、友人との会話、オンラインミーティング、交流会などにおいて、自然なコミュニケーションをサポートすることを目的としています。

---

## 開発背景

会話の中では、話題が尽きたり沈黙が生まれたりする場面が少なくありません。

TalkSeedは、そのような状況においてAIが会話の「種（Seed）」を提供することで、会話を円滑に進められるよう支援することを目指しています。

---

## 主な機能（予定）

* 話題提案
* アイスブレイク質問の生成
* 会話内容に応じた追加質問の提案
* ツッコミやリアクションの生成
* 会話の盛り上がり度分析
* ユーザーに合わせた話題のカスタマイズ
* リアルタイム会話支援

---

## 想定利用シーン
