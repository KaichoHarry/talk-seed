# AI会話支援システム 音声変換機能 要件定義書

---

## 1. システム概要

待ち時間中の利用者同士の会話を支援するため、AIが会話へ参加し話題提供や会話補助を行う。

本担当機能では、AIが生成した発話テキストを自然な音声へ変換し、スマートフォンのWebブラウザ上で再生する機能を開発する。

---

## 2. 利用者定義（アクター）

| アクター | 説明 | できる操作 |
|----------|------|-----------|
| 利用者 | システム利用者 | 音声設定変更、音声再生 |
| AI会話生成機能 | AIによる会話生成モジュール | 発話テキスト送信 |
| 音声変換機能 | 本担当機能 | テキストを音声へ変換 |

## 4. 機能要件

### 4-1. 音声生成機能

- [x] AI生成テキストを受信する
- [x] テキストを音声データへ変換する（サーバー側でedge-ttsによりmp3を生成）
- [x] 音声生成結果を返却する（base64エンコードしたmp3をJSONで返却）

### 4-2. 音声設定機能

- [x] 音声タイプ変更（女性／男性の2種類。実装ではロボット音声を廃止）
- [x] 話速変更（クライアント側で`Audio.playbackRate`に反映。edge-tts自体の生成速度は変更しない）
- [x] 音量変更（クライアント側で`Audio.volume`に反映）

### 4-3. 音声再生機能

- [x] 生成音声を再生する（ブラウザの`Audio`要素で再生）
- [x] 再生停止ができる（`onended`で状態表示を「音声は停止中です」に戻す。利用者による明示的な停止ボタンは無い）
- [x] 再生終了を通知する（読み上げ状態のテキスト表示を切り替えることで通知）

---

## 5. 非機能要件

### 5-1. 性能

- [x] 音声生成時間は3秒以内（実測値: 約1秒、開発環境）
- [x] 音声再生遅延を最小限にする

### 5-2. 可用性

- [x] 音声生成失敗時もシステムを停止させない（トースト通知でエラーを表示し、読み上げ状態を「音声は停止中です」に戻す）
- [x] 音声未生成時はエラーメッセージを表示する

### 5-3. 操作性

- [x] スマートフォンから操作可能
- [x] ブラウザのみで利用可能
- [x] インストール不要

## 8. 機能詳細

### 8-1. generate（音声生成）

- [x] アクター：AI会話生成機能
- [x] 概要：AI生成テキストを音声へ変換

#### 入力

- text

#### 出力

- 音声データ（base64エンコードされたmp3）

---

### 8-2. play（音声再生）

- [x] アクター：利用者
- [x] 概要：生成音声を再生

#### 出力

- 音声再生開始

---

### 8-3. stop（音声停止）

- [x] アクター：利用者（実装では利用者が明示的に止める操作は無く、再生終了時に自動で状態表示が戻る）
- [x] 概要：再生中の音声を停止

---

### 8-4. change_voice（音声変更）

- [x] アクター：利用者
- [x] 概要：音声タイプを変更

#### 選択肢（実装）

- 女性音声（ja-JP-NanamiNeural）
- 男性音声（ja-JP-KeitaNeural）

当初案にあった「ロボット音声」（ja-JP-KeitaNeuralをベースにピッチ-45Hz・話速-15%）は実装後に削除した。

---

### 8-5. set_volume（音量変更）

- [x] アクター：利用者
- [x] 概要：音量を変更

#### 範囲（実装）

音声設定画面のスライダーは0〜100%（初期値80%）で、クライアント側で`Audio.volume`（0.0〜1.0）に変換して反映する。

---

### 8-6. set_rate（話速変更）

- [x] アクター：利用者
- [x] 概要：話す速度を変更

#### 範囲（実装）

音声設定画面のスライダーは50〜180（初期値100＝「ふつう」）で、クライアント側で`Audio.playbackRate`（0.5〜1.8倍）に変換して反映する。edge-tts側の生成速度（`rate`パラメータ）は常に`+0%`固定で、話速の変更はあくまで再生速度の調整である。

## 11. 実装メモ（サーバー/クライアントの役割分担）

実装では上記の関数群を以下のように分担している。

| 関数 | 実装場所 | 実装 |
|---|---|---|
| generate_speech | サーバー (`backend/voice/service.py: synthesize_speech`) | edge-ttsで音声合成し、`POST /voice/speak`でbase64のmp3を返す |
| change_voice | サーバー | `voice_type`("female"/"male")に応じて`VOICE_PROFILES`から音声・ピッチを切り替える（"robot"は削除済み） |
| play_audio / stop_audio | クライアント (`frontend/src/App.tsx: speak`) | 受け取ったbase64をdata URLにし、ブラウザの`Audio`要素で再生する |
| set_volume / set_rate | クライアント | `Audio.volume` / `Audio.playbackRate` に音声設定画面の値を反映する |
